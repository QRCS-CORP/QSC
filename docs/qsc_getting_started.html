01 / DISCOVERY

Choose a component

Start with the subject-based catalog, which links to the actual header reference pages in this documentation snapshot. Each file reference documents declarations and usually provides a link to the generated source listing.

For example, explore Kyber key encapsulation, AES encryption, or SHA-3 and Keccak. The Doxygen file list remains available for exhaustive browsing.

02 / API CONTRACTS

Read the declaration and its documentation together

Review the function's parameter types, documented input and output buffer sizes, success/failure conventions, and preconditions. Follow its More... details link where present. Cross-reference macros, enums and state structures rather than inferring sizes or behavior from a function name.

Practical rule

For security-sensitive operations, do not infer memory ownership, constant-time properties, implicit initialization or thread safety unless those properties are explicitly documented or verified from the matching source revision.

03 / LIFECYCLE

Track state, lifetime and ownership

Many cryptographic routines operate on caller-owned state. Before connecting any operations, inspect the associated structure and initialization, update, finalization and disposal functions where applicable.

Document who allocates and clears sensitive buffers, when an operation may be repeated, and whether an API mutates its inputs. See the data structure index and memory utility reference.

04 / PORTABILITY

Check platform and build requirements

The API includes platform-facing facilities for CPU capabilities, system information, threading, and networking. Review compile-time feature guards, supported toolchains and instruction requirements in the actual project build configuration.

Optimized execution paths may depend on compile-time targeting as well as runtime CPU features. This documentation snapshot is not a substitute for a verified build profile.

05 / QUALIFICATION

Verify the integration

Build against the exact source revision corresponding to the API reference. Validate known-answer vectors, error handling, buffer boundaries and interoperability for every enabled algorithm. Review the relevant test headers and the library's qualification procedures.

The presence of an algorithm or platform in these pages is not itself a claim of certification or suitability for a particular deployment.
