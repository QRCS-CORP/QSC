Detailed Description

Blocking socket adapter around qsc_tls_connection.

This header provides a minimal transport adapter that binds a qsc_tls_connection to a qsc_socket and drives the TLS engine using blocking send and receive calls. The adapter does not allocate or own the engine or the socket. It only stores non-owning pointers and marshals bytes between the engine record interface and the socket API.

◆ qsc_tls_io_handshake()

QSC_EXPORT_API qsc_tls_status qsc_tls_io_handshake ( qsc_tls_io_connection * io)

Drive the TLS handshake to completion over the attached blocking socket.

Repeatedly calls the TLS engine handshake function, flushing any produced outbound flight to the socket and receiving additional input whenever the engine requires more record bytes. The call returns when the handshake completes or a fatal error occurs.

Parameters
io[struct*] The attached I/O adapter.
Returns
[qsc_tls_status] Returns qsc_tls_status_success on success.

Receive and decrypt application data from the attached socket.

Receives socket bytes until at least one protected TLS record has been consumed and any decrypted application payload has been written to the caller-supplied buffer.
