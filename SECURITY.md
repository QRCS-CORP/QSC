# Security Policy

## Supported Versions

We support the latest release of QSC. Previous versions may not receive security updates.

| Version | Supported |
|---------|-----------|
| latest  | ✅        |
| older   | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability in this library, **please report it responsibly**:

- Email: [contact@qrcscorp.ca](mailto:contact@qrcscorp.ca) 
- GitHub Issues: _Do not use public issues to disclose vulnerabilities._  
- Please provide:
  - A description of the issue
  - Steps to reproduce or proof-of-concept
  - Impact and affected components

We aim to respond within **7 business days**, and fix verified vulnerabilities within **30 days**.

## Public Disclosure

We will publicly disclose resolved issues in a security advisory, coordinated with the reporter.

Thank you for helping keep QSC secure.
